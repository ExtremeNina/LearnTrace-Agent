## 完成记录（2026-10-05）

- **后端**：`GET /search?q=`（SearchController + GlobalSearchServiceImpl）——与 Agent 工具 rag_search 同一向量库与 userId 硬过滤口径，返回结构化结果
  SearchResultVO（type / refId / courseId / tsSec / subject / wrong / snippet）；来源 ID 从向量文档 ID 前缀解析
  （q: → 题目 / note:{id}:{块} → 笔记 / transcript:c{courseId}:{seg} → 网课 + tsSec），相似题（sq:）无法回跳来源不入结果，坏 ID 跳过不报错
- **前端**：顶栏搜索框（桌面端）——300ms 防抖语义搜索 + Enter 立即搜 + Ctrl+K / Cmd+K 聚焦；结果按 网课 / 笔记 / 题目 分组下拉，
  网课带 [mm:ss] 时间戳跳转、笔记走 /notes?open={id} 直达（Notes.vue 增加 open 参数，KeepAlive 下经 onActivated 处理）、题目走 /questions?open={id}
- 未做（后置）：混合检索（关键词 + 向量）与重排序仍属 B10 二期；结果聚合独立页面未做（下拉面板够用）
