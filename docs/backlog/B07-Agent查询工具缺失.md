# B07 Agent 缺少查询类工具

- 优先级：P2　|　模块：Agent / 笔记　|　来源：Spec 轴（PRD §3.1/§3.4）
- 状态：待办

## 问题
PRD §3.1“Agent 通过知识点页 + 知识联系 + 搜索理解知识与学习资料的关系”、§3.4“AI 整理、AI 修改（进入 Agent 会话确认）”。当前 Agent 仅有 saveQuestion 与 rag_search 两个工具，无任何查询笔记/课程/题目的工具——§3.1 的查询资料、分析学习情况均不可用。

## 影响
Agent 对学习资产的“理解”能力缺位；AI 修改笔记无数据来源。

## 建议
新增笔记/课程查询工具（只读，无需确认卡），作为 AI 修改笔记与 RAG 出题的前置。
