# B11 对话上传视频：语音转写 + 保存笔记

- 优先级：P1（内容输入）　|　模块：Agent 对话 / 网课 ASR / 笔记　|　来源：2026-10-04 用户提出（取代旧「方案 B：轻量抽帧预览 + 确认后归档」讨论，即原 agent.md 当前待办 6）
- 状态：**已完成（MVP 2026-10-05）**　|　模块文档：`docs/modules/agent-chat.md` 视频转写一节

## 完成记录（MVP 2026-10-05）

**架构（用户拍板）**：转写能力全部封装为 Agent 工具由 LLM 调度（不走向课式确定性流水线）；转写为「提交任务」型异步工具（秒回不阻塞回合），进度与结果经消息更新 + WS 推送回流对话（方案 A 后台继续，切页不中断）。

- **媒体工具抽取**：`utils/MediaUtils`（ffprobe 时长 / 抽音频 / run），CoursePipelineService 改为复用（B20 语音笔记可直接复用转写服务）
- **转写服务**：`TranscriptionService`——提交时创建 `video_transcript` 占位消息，courseExecutor 异步执行「抽音频 → 280s 分片 → Qwen ASR → 时间戳偏移合并」，每片完成更新消息 payload 进度并推送 `TRANSCRIBE` 事件；完成后占位消息原地更新为 `[mm:ss]` 全文 + 追加 Redis 会话记忆；原片上传 OSS 永久保留并回填用户消息 `video_url`
- **Agent 工具**：`TranscribeVideoTool`（提交，ToolContext 带视频临时路径/时长）+ `CreateNoteTool`（保存转写笔记：分组同名复用/自动创建，sourceType=2 对话转写，全文由服务端从最近转写消息确定性获取不经模型复述）
- **消息模型**：message 表加 `video_url` 列（sql/video_message.sql）；用户视频消息 `msgType=video`，不入图片 OCR 链路
- **WS 基建**：`AgentEventPushService`（userId→session 注册表，多标签页支持）+ `ChatEvent.TRANSCRIBE` 事件（status/done/total）
- **上传**：`POST /upload/chat-video`（ChatVideoService）——500MB + 格式白名单 + **同步 ffprobe 时长校验（>30 分钟秒级拒绝并引导去「学习资产 → 视频管理」上传完整网课）**
- **Prompt**：`AgentPrompts.VIDEO_PROMPT`（BASE_PROMPT + 视频段：触发转写时机 / 不编造内容 / 保存前给分组名与标题并征得确认）
- **前端**：附件菜单（图片/视频）+ 视频预览位 + 转写进度气泡（「正在转写第 x / y 段…」）+ 转写完成折叠展示（查看全文）
- **测试**：单测 173 个全通过（新增转写任务 / 保存工具 / 时长校验 / ChatEvent）；真实视频端到端冒烟通过（video4 243s 单片、video5 874s 4 分片：进度事件 → 全文回填 → videoUrl 回填 → LLM 保存笔记闭环 source=对话转写）

## 需求（用户口径，2026-10-04）

- 对话输入框支持上传视频，仅限 30 分钟以下
- 只做语音转写：不抽帧 OCR、不做 LLM 整理（与网课流水线区分的轻量路径）
- 转写成功后用户可保存到「笔记整理」；未指明分组时默认新建分组 + 新笔记存放转写内容，分组名 / 笔记名由 LLM 命名
- 保存属创建用户数据，须对话明确确认后才执行（硬性规范）
