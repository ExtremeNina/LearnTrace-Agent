# B14 练习 / 测验模式

- 优先级：P0-3（学习闭环）　|　模块：题目 / 复习　|　来源：路线图（2026-10-03 用户制定）
- 状态：**已完成（MVP 2026-10-04）**　|　依赖：B12 复习系统（已完成 ✅）　|　成本：中

## 完成记录（MVP 2026-10-04）

- **后端**：`GET /quiz/pick` 无状态组卷抽题（QuizController/ServiceImpl）——题库 = question_record + similar_question，按学科/时间段/来源筛选，`ORDER BY RAND()` 每来源入池上限 200，Java 侧洗牌取题（`shufflePick` 纯函数 + 单测）；不建会话/成绩表
- **批量加卡**：`POST /review/cards/batch`（ReviewService.addCardsBatch）——已在队列/无效项/来源不存在计为 skipped 不中断整批，复用 addCard 去重与恢复逻辑
- **前端**：/quiz 三阶段页（配置组卷 → 一屏一题作答 + 正向计时 → 结果对照自评），错题勾选批量入复习队列；入口 = IconRail「练习测验」+ /review 统计首屏「做组练习测验」按钮
- **设计决策**：题库均为文本问答形态（无选择题选项字段）不自动判分，用户对照参考答案自评；成绩归档后置
- 模块文档：`docs/modules/quiz.md`

## 能力

- 从知识点 / 学科 / 时间段批量出题（5 题、10 题）；计时、先做后看解析
- 结果沉淀进错题本 → 进入复习队列

## 复用

相似题生成、RAG 检索、错题本

## 新增

批量出题接口、答题 UI、计时、成绩归档
